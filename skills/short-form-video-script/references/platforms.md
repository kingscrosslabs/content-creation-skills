# Platforms: talking-head scripts for Instagram Reels, TikTok and YouTube Shorts

The script method is the same on all three: hook, value, rehook, CTA, under a minute by default. What changes is how long a video can be, what the platform rewards, and what the CTA can promise. Platform rules change often; anything marked "(verify)" should be checked against the platform's current help pages before you rely on it.

## Length

| | Max length | Default target for this skill |
| - | - | - |
| Instagram Reels | up to 3 minutes (verify) | under 60 seconds |
| TikTok | up to 10 minutes in the app (verify) | under 60 seconds |
| YouTube Shorts | up to 3 minutes (verify) | under 60 seconds |

Under 60 seconds stays the default because it cross-posts cleanly and keeps completion rates high. Go longer only when the user asks, and keep the one-beat-per-line body so the extra time is more steps, not padding. At a normal speaking pace, 60 seconds is about 150 words.

- **TikTok:** videos over 1 minute are the ones eligible for TikTok's Creator Rewards Program (verify). If the user is chasing that, aim for 61–90 seconds and add steps or examples, not filler.
- **YouTube Shorts:** Shorts over 1 minute with a Content ID claim (for example, copyrighted background music) may be blocked (verify). Keep longer Shorts free of claimed audio.

## What each platform rewards

- **Instagram Reels:** Instagram has said sends (shares by DM) and watch time are among its strongest signals for reaching new people. The personal story and a sharp Shareability Score matter most here. Instagram also shows reposted content and videos with other platforms' watermarks less, so upload a clean file.
- **TikTok:** watch time, completion, rewatches, comments and shares. People use TikTok as a search engine, so say the topic's keywords out loud in the first lines; spoken words feed the auto-captions (verify how much they count for search). The curiosity-gap arc suits TikTok well.
- **YouTube Shorts:** YouTube Studio shows "viewed vs. swiped away" for Shorts, so the first seconds are scored directly. After that, retention and replays. A Short can link to one of the user's long videos as a related video, which makes Shorts a good top-of-funnel step toward longer content.

## On-screen text and captions

- The platform's buttons and caption cover the bottom and right of the frame on all three. Keep text overlays in the upper-middle.
- Burned-in captions help because many people watch without sound. Each platform also offers auto-captions (verify availability per account).
- The caption under the video is a separate piece; write it with `short-form-video-caption`. Rough limits: Instagram 2,200 characters; TikTok 4,000 characters (verify); YouTube Shorts title 100 characters, description 5,000 characters.

## CTAs per platform

- **Instagram:** "Comment [KEYWORD] and I'll send it to you" works when the user has a way to send DMs automatically when someone comments. Check that they do before promising it.
- **TikTok:** the same comment-keyword CTA works for engagement, but automatic DMs on TikTok are more limited (verify the user's setup). If DMs aren't set up, point to the link in bio instead.
- **YouTube Shorts:** links in Shorts descriptions and comments aren't clickable. Swap "comment for the link" for "the full walkthrough is on my channel", or link a related long video.
- **AUTHORITY CTA** ("Do you agree? Tell me in the comments" + follow line) works the same on all three.

## Posting one script to all three

- Film once at 9:16 with the text overlay in the safe zone.
- Keep the spoken script identical; adapt only the CTA line per platform (see above) if the user can record alternate endings.
- Upload a clean file to each platform, never a download with another platform's watermark.
