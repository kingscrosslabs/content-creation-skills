# AEO/SEO profile

Everything the AEO/SEO skills need to know about content-creation-skills.com. Every skill opens this file first, then opens only what its task needs.

Keep this file short. It's an index, not a strategy doc.

---

## Read for every task

| File | What's in it |
|---|---|
| `site.md` | The website: domain, stack, where each page type lives, the commands to scaffold, check, preview and ship, what the site generates automatically, and the OpenSEO project |
| `product.md` | What you sell, who it's for and who it isn't for, what makes it different, the voice, and the files that hold the true product facts |
| `aeo-seo-log.md` | The **Decisions** table (read all of it) and the dated log (read the last two weeks) |

These three are the minimum. No skill runs without them.

## Read when the task needs it

| File or folder | What's in it | Open it when... |
|---|---|---|
| `competitors.md` | Who you compare against, with sourced, dated facts | Writing a comparison page or a listicle, or a post that mentions alternatives |
| `query-bank.md` | Every query considered or targeted, its search data and its status | Planning topics or picking a page's target query |
| `experience-bank.md` | Your own stories, data and quotes, marked approved or pending | Drafting any page. Only `approved` entries go on the site |
| `user-questions.md` | Threads where real people ask about your topic | Planning topics, writing FAQs, drafting forum replies |
| `link-targets.md` | Lists, directories and newsletters worth pitching | Drafting link pitches |
| `research/` | One report per page, plus saved search results in `serps/` | Before any paid OpenSEO call, and when updating a page |
| `../BRAND.md` | Strategy, audience, positioning, voice, vocabulary and claims rules | Writing any copy |
| `../DESIGN.md` | The visual system shared with aeo-seo-skills.com | Building or styling any page |

**Quick picks:**
- **Blog post:** the three "every task" files, then `query-bank.md`, `experience-bank.md`, `user-questions.md` and `research/`.
- **Comparison page:** the three "every task" files, then `competitors.md` and `research/`.
- **Topic plan:** the three "every task" files, then `query-bank.md` and `user-questions.md`.
- **Weekly routine:** everything above.
