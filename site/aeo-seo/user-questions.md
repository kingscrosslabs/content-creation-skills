# User questions

Real questions from forums, Reddit and communities, in the asker's situation. `query-bank.md` holds the phrases you target; this file holds the evidence behind them: what people asked, what they tried, and what blocked them.

**How it's used**
- **New pages:** when 3 or more open questions cluster around something no page answers, propose it in the next topic plan.
- **FAQs on live pages:** a question a live page doesn't answer becomes an FAQ on that page.

**Rules**
- Paraphrase the question. Don't paste the post.
- No personal names or account handles. A company only if the asker named it publicly in the thread.
- Map every entry to at least one query in `query-bank.md`, adding new queries there with the same wording.

## Format

```
### UQ-<nnn> · <short label>
- Seen: YYYY-MM-DD · Where: <forum or subreddit> · URL: <url>
- Asked: <paraphrase>
- Blocker: <what it stops them doing>
- Tried: <what they already tried>
- Queries: <query-bank queries this maps to>
- Status: <open | answered-by: slug | partial: slug>
- Gaps: <what your page doesn't answer yet, or "none">
```
