# Research

Research for each page, kept so nothing gets bought or looked up twice. The page skills write and read these files.

- `<slug>.md`: one report per page. It holds the keyword table (keyword, volume, KD, CPC, intent, date), the read of the results page, the overlap check against your other pages, the user-quote shortlist with links, the product and competitor facts with sources, the decisions (target query, format, length, title), and the OpenSEO credits spent. Updating a page starts from this file.
- `serps/<query-slug>.md`: one saved results page from OpenSEO `get_serp_results`. It holds the date, the top 20 organic URLs and titles, the People Also Ask questions, whether an AI Overview appeared, and a one-line note on each top-5 result's format and length. Reuse it for 30 days before paying for a fresh one.
- `audits/`: technical audit reports (`technical-audit-<date>.html`) and the raw evidence for each run (`<date>/`), written by `aeo-seo-technical-audit`. A re-audit compares against the last one.

Keyword metrics live in `../query-bank.md`, reused for 90 days.
